TECH STACK:
- Backend: FastAPI (Python 3.11+), SQLAlchemy + PostgreSQL
- LLM: Groq API — openai/gpt-oss-120b (chat), whisper-large-v3-turbo (STT)
- Web search: Tavily API for live govt policy/form lookups
- TTS: edge-tts (ur-PK-AsadNeural voice), streamed as audio blob
- Frontend: React 18 + TypeScript + Vite + Tailwind CSS

CORE FLOW:
1. User speaks (mic button, MediaRecorder) or types Urdu text
2. Audio → Groq Whisper → Urdu text transcript
3. Text → Groq LLM (with Tavily tool-call for live info when needed) → Urdu response
4. Response → edge-tts → auto-plays if input was voice; "🔊 Read Aloud" 
   toggle if input was text
5. Session + message history saved to Postgres (2 tables: sessions, messages)
